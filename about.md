# Late Click Buffer

Click whenever you like. If clicking on this exact frame would kill you, the click is **held** and sent on the first frame where clicking lets you survive (checked by simulating the next few ticks with the game's own physics).

- Toggle it in the mod settings.
- Settings: max wait, survive-check length, per-click time budget.

Changes your input timing - runs made with it are not legit for lists.
